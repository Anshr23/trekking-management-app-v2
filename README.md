# Trekking Management Application V2

A full-stack web application developed for the Modern Application Development II course.

The application provides a platform for managing trekking activities involving three types of users:

- Admin
- Trek Staff
- Trekkers

The system supports trek management, staff assignment, trek bookings, booking history, scheduled reminders, monthly reports, asynchronous CSV exports, and Redis caching.

## Technology Stack

- Flask
- Vue.js
- Bootstrap
- SQLite
- Redis
- Celery
